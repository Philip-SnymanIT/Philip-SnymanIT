## 🏆 Final Boss: UnderSoil

**[UnderSoil](https://github.com/Philip-SnymanIT/UnderSoil)** is my capstone and the project I'm proudest of: an offline-first smart agriculture platform that helps farmers with poor connectivity manage irrigation and catch crop disease early.

- 🧭 Led a team of 4 as **Project Lead & Lead Backend Developer**
- ⚙️ ASP.NET Core 8 Web API with EF Core and SQL Server, secured with JWT
- 📡 ESP32 irrigation node talking to the API over MQTT
- 📱 Android app with offline sync and on-device plant-disease detection (TensorFlow Lite)
- 🖥️ Web admin dashboard to manage sectors, devices, reports and users

### 🗺️ Other Levels Cleared
